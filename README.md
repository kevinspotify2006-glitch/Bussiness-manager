# Business Manager

Een direct speelbare browser-versie van Business Manager in Northgate.

## Spelen

Open `index.html` in een browser. Er zijn geen downloads, npm-installaties of externe services nodig.

## Gameplay

- Start met €25.000 cash.
- Open verschillende bedrijfstypes.
- Verdien omzet per handelsuur.
- Houd cash, winst, reputatie en awareness in de gaten.
- Gebruik marketing om vraag en awareness te verhogen.
- Bekijk de stadskaart en managementrapporten.
- Laat de simulatie automatisch doorlopen of gebruik de snelle acties.

De repository is bewust als zelfstandige browserbuild ingericht zodat hij zonder lokale development-omgeving geopend kan worden.
